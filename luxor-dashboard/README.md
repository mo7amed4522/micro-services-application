# Luxor Dashboard

A modern Vue.js dashboard application with Tailwind CSS for the Luxor microservices platform.

## Features

- 🎨 **Modern UI**: Built with Tailwind CSS and custom design system
- 📱 **Responsive**: Mobile-first responsive design
- 🚀 **Vue 3**: Latest Vue.js with Composition API support
- 🎯 **TypeScript Ready**: Easy migration to TypeScript
- 📊 **Dashboard Components**: Pre-built dashboard components
- 🔧 **Configurable**: Easy to customize and extend

## Tech Stack

- **Frontend**: Vue.js 3
- **Styling**: Tailwind CSS
- **Icons**: Heroicons
- **Routing**: Vue Router 4
- **State Management**: Vuex 4
- **Build Tool**: Vue CLI

## Quick Start

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Navigate to the dashboard directory
cd luxor-dashboard

# Install dependencies
npm install

# Start development server
npm run serve
```

The application will be available at `http://localhost:8080`

### Available Scripts

```bash
# Development server
npm run serve

# Build for production
npm run build

# Lint and fix files
npm run lint

# Preview production build
npm run preview
```
