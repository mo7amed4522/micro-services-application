# Luxor App - Your Ultimate Guide to Ancient Egypt 🏺

![Luxor Logo](luxor-app/Assets.xcassets/logo-nobg.imageset/luxor-logo.jpg)

## Overview

Luxor App is a comprehensive iOS application designed to provide tourists and history enthusiasts with an immersive experience exploring the ancient wonders of Luxor, Egypt. Built with cutting-edge technology and powered by a robust microservices architecture, the app offers fast, friendly, and secure access to Egypt's rich historical heritage.

## 🏗️ Technical Architecture

### **iOS App (Swift)**
- Built with **SwiftUI** and **Composable Architecture (TCA)**
- Responsive design with custom themes and animations
- Multi-language localization support
- Offline-first approach with local caching

### **Microservices Backend (Go)**
- **API Gateway**: NestJS-based gateway for request routing
- **User Service**: Authentication and user management
- **Pharaoh Service**: Historical data and pharaoh information
- **Quiz Service**: Educational content and quiz management
- **Chat Service**: Real-time messaging and communication
- **Transaction Service**: Payment processing and financial operations
- **Wallet Service**: Digital wallet and balance management
- **Upload Service**: File management and media storage
- **Card Service**: Payment card management
- **Feedback Service**: User feedback and rating system

### **Database & Storage**
- **PostgreSQL**: Primary database for structured data
- **AWS S3**: Media file storage and content delivery
- **Redis**: Caching and session management
- **gRPC**: High-performance inter-service communication
